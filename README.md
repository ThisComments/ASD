# Лабораторные работы по C++

Репозиторий с лабораторными работами по дисциплине, выполненными на C++.

## Структура

Каждая лабораторная работа находится в отдельной папке:

```text
.
├── Lab1/
├── Lab2/
├── Lab3/
└── README.md
```

Внутри каждой лабораторной:

```text
Lab1/
├── build/
│   ├── lab1
│   └── out.txt
├── lab1.cpp
├── task/
│   └── task.txt
└── tests/
    ├── test.txt
    ├── test2.txt
    ├── ...
    └── test14.txt
```

### Назначение папок и файлов

* `LabN/` — отдельная лабораторная работа.
* `*.cpp` — исходный код лабораторной работы.
* `task/` — условие лабораторной работы.
* `tests/` — тестовые входные данные для проверки программы.
* `build/` — скомпилированные файлы и результаты запуска программы.
* `out.txt` — вывод программы при тестировании.

## Компиляция и запуск

Перейдите в папку нужной лабораторной:

```bash
cd Lab1
```

Создайте папку `build`:

```bash
mkdir -p build
```

Скомпилируйте программу:

```bash
g++ lab1.cpp -o ./build/lab1
```

Запустите программу:

```bash
./build/lab1
```

Для проверки на тестовых данных можно перенаправить вход из файла:

```bash
./build/lab1 < tests/test.txt
```

Чтобы сохранить результат в файл:

```bash
./build/lab1 < tests/test.txt > build/out.txt
```

Для других лабораторных название исходного файла и исполняемого файла может отличаться.

# Лабораторные работы по C++

Репозиторий с лабораторными работами по дисциплине, выполненными на C++.

## Структура

Каждая лабораторная работа хранится в отдельной ветке:

* `lab1` — лабораторная работа №1
* `lab2` — лабораторная работа №2
* `lab3` — лабораторная работа №3
* и т. д.

Ветки содержат исходный код соответствующих лабораторных работ.

## Используемые технологии

* C++
* Стандартная библиотека C++
